# DevDirectory — Midnight Neon

## Run locally
1. Install Node.js LTS.
2. Extract the ZIP and open this folder in VS Code.
3. In the terminal run:
   ```bash
   npm install
   npm run dev
   ```
4. Open the local URL Vite prints (usually http://localhost:5173).

## Features
- React + Vite
- Midnight Neon theme, purple/cyan glow and glassmorphism cards
- 50 fictional sample developer profiles from countries around the world
- Search by name, role, location, skill and email
- Location, skill, experience and sort filters
- Responsive desktop, tablet and mobile layouts
- Sample profile photos from Random User portrait URLs; cards fall back to initials if images fail

## Demo-data notice
All 50 developer records are fictional, randomly composed sample data. `example.com` email addresses are reserved placeholders, and GitHub links point to the generic GitHub homepage. The portrait images are random sample photos and do not represent the fictional names. Replace these values with real details only when you have permission.
